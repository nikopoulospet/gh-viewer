gh-viewer

GitHub App

gh-viewer ships with its own App, so there is nothing to fill in here. Override the Client ID only to point at an App you registered yourself; clearing the field restores the built-in one. It is a public identifier either way — gh-viewer holds no secret.

Saved queries

Each query is a GraphQL document plus variables. List path points at the array to render (e.g. search.nodes); count path is optional and only feeds the status line. Rows drill down by node id, so keep id in the selection.
